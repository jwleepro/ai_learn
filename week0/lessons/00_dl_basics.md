# 00. 딥러닝 기초를 “코드로” 잡기 (LLM 들어가기 전)

목표: 수학을 외우기보다, **LLM을 구성하는 계산**(선형결합/행렬곱/경사하강/활성화)을 코드로 체감합니다.

> 이 레슨은 Week 0의 “기초 다지기” 파트입니다.  
> 끝까지 이해 못해도 괜찮고, **직접 실행해보고 결과가 왜 그런지**만 잡으면 됩니다.

## 1) 뉴런 1개는 중학교 수학이다: `y = w*x + b`

- `x`: 입력
- `w`: 가중치(입력이 출력에 얼마나 반영될지 정하는 값)
- `b`: 편향(입력이 0이어도 더해지는 기본값)

코드로는 그냥:

```python
def simple_neuron(x, w, b):
    return (w * x) + b
```

LLM도 결국 이런 계산이 엄청 많이 쌓여 있습니다.

---

## 2) 행렬 곱셈 = 반복문을 한 번에 처리

입력이 여러 개이고 출력도 여러 개면, `for`를 돌릴 수도 있지만 딥러닝은 보통 **행렬곱으로 한 방에** 계산합니다.

예: `[햄버거, 감자튀김, 콜라]` 판매량으로 `[매출, 순이익]`을 계산:

- 입력 `x` (3개)
- 가중치 `W` (2x3)
- 편향 `b` (2개)
- 출력 `y = W @ x + b`

실습 코드는 [`week0_dl_basics.py`](../code/week0/week0_dl_basics.py)에 있습니다.

## 3) 학습(Training) = `w, b`를 자동으로 찾는 과정

모델이 어떤 정답 `y_true`를 맞히게 하려면,
모델 예측 `y_pred`가 정답과 가까워지도록 `w, b`를 조정해야 합니다.

가장 흔한 방식이 **경사하강법(Gradient Descent)** 입니다:

- 지금 위치의 기울기(오르막 방향)를 보고, 그 **반대 방향**으로 조금씩 이동

비유: 눈을 감고 산에서 내려온다고 상상하세요.
발밑을 더듬어 “어느 쪽이 가장 가파른 오르막인지” 알아내고, 그 반대 방향으로 한 걸음 옮깁니다.
이것을 반복하면 결국 낮은 곳(loss가 작은 곳)에 도달합니다.

> **기울기(gradient)**: loss가 가장 빨리 커지는 방향과 크기를 알려주는 값
> loss를 줄이려면 그 **반대 방향**으로 움직입니다.
>
> **학습률(lr)**: “한 걸음의 크기” — 너무 크면 넘어가고, 너무 작으면 느림

우리는 아주 단순한 **직선 맞추기(선형회귀)**로 감을 잡습니다:

- 데이터 `(x, y)`가 있을 때 `y ≈ w*x + b`
- MSE loss(평균제곱오차: 예측과 정답의 차이를 제곱해서 평균낸 것)를 줄이도록 `w, b`를 업데이트

### 왜 저 계산식이 나올까? (`x, y`는 고정이고 `w, b`만 바뀐다는 점부터 보기)

핵심은 **무엇이 고정이고 무엇이 학습으로 바뀌는지**입니다.

- `x, y`: 이미 주어진 데이터라 고정
- `w, b`: 모델이 학습하면서 조정하는 값

그래서 여기서 손실은 사실상 **`MSE(w, b)`** 로 볼 수 있습니다.

- `y_pred = w*x + b`
- `err = y_pred - y = (w*x + b - y)`
- `loss = mean(err²) = mean(((w*x + b - y)²))`

이제 한 샘플만 있다고 생각하면 `loss = err²` 입니다.
이 값을 `w`로 미분할 때는 바깥쪽부터 보면 됩니다:

1. 바깥 제곱 `err²`를 미분하면 `2 * err`
2. 안쪽 `err = w*x + b - y`를 `w`로 미분하면 `x`
3. 그래서 한 샘플 기준으로 `d(loss)/dw = 2 * err * x`

2번에서 `x`가 남는 이유는:

- `b`, `y`는 `w`와 관계없으므로 미분하면 0
- `w*x`만 `w`에 따라 바뀌므로 미분 결과가 `x`

데이터가 여러 개면 평균을 내므로:

- `dw = (2/n) * sum(err * x)`

이 식은 "`x`가 크면 무조건 `w`가 크게 변한다"는 뜻이 아닙니다.
더 정확히는, **같은 오차 `err`라면 `x`가 큰 샘플일수록 `w`에 대한 기울기 `dw`에 더 크게 기여한다**는 뜻입니다.
왜냐하면 `w`를 조금만 바꿔도 `w*x + b`에서 `x`만큼 곱해져 예측값이 더 크게 움직이기 때문입니다.

**b는?**

`err = w*x + b - y`를 `b`로 미분하면 `1`만 남습니다.
즉, 한 샘플 기준으로는 `d(loss)/db = 2 * err`이고, 여러 개 평균을 내면:

- `db = (2/n) * sum(err)`

코드로 보면 (`mean = sum/n`이므로 `mean(…)` 대신 `sum(…)/n`으로 쓴 것):

```python
dw = (2/n) * sum(err * x)   # 각 샘플이 w 기울기에 기여한 값을 평균낸 것
db = (2/n) * sum(err)       # b는 미분하면 1만 남으므로 오차 평균 형태가 됨
w -= lr * dw                # loss를 줄이려고 기울기 반대 방향으로 이동
b -= lr * db
```

> `2`가 붙는 이유는 제곱 `err²`를 미분하면 `2 * err`가 되기 때문입니다.
> 이 `2`는 상수라서 학습률(`lr`)에 흡수해도 학습 방향 자체는 같습니다.
> 더 깊이 들어가면 편미분/연쇄법칙 이야기로 이어지지만, 여기서는 **"x, y는 고정이고 w, b만 바뀐다"**는 관점만 잡아도 충분합니다.


## 4) 활성화 함수(Activation): “비선형성” 넣기

선형만(행렬곱만) 계속 쌓으면, 결국 “큰 선형”이 됩니다.  
그래서 중간에 비선형 함수(예: ReLU)를 넣어 더 똑똑한 함수가 되게 합니다.

- ReLU: `max(0, x)`
- tanh, sigmoid 등(지금은 이름만)

LLM의 MLP(FFN) 안에도 이런 비선형이 들어갑니다.
